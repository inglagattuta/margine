# Margine

Aprire `index.html` nel browser o servire la cartella del progetto con un server statico. Nessuna dipendenza o compilazione richiesta.

Calcolo: costo = (ore × tariffa + materiali + altre spese) × (1 + riserva / 100). Prezzo = costo / (1 − margine / 100). Il margine è una percentuale del prezzo, non un ricarico sul costo.

Per stampare il preventivo usare il pulsante Stampa / PDF, quindi Salva come PDF nel browser. I costi interni non compaiono nel preventivo cliente. Il prezzo proposto nel campo di confronto è solo una simulazione; il preventivo usa sempre il prezzo obiettivo.

Stato commerciale: prototipo utilizzabile, nessun pagamento collegato. Piano di lancio in `guida-commerciale.md`.
